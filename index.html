Selected work

Alibaba · Amap

Senior Algorithm Engineer
Dec 2023 — Apr 2026

Led algorithm development for turn-by-turn navigation voice guidance, bringing sequential and multi-task models into a service handling 200M+ daily navigation sessions.

From rules to learned guidance

Jointly modeled when to speak, which maneuver to describe, what to say, and playback order. Combined cloud-computed road representations with on-device inference using MNN.

Route deviation rate: 5.16% → 5.14% · Full production rollout

Learning from driver response

Designed the NIQ user-compliance metric and used high-compliance trajectories to refine timing labels and fine-tune guidance models.

Subsequent iteration: route deviation rate 5.12% → 5.11%
Modeling and deployment details

Trained on 1.56B trajectory samples. Used causal self-attention for broadcast history, CrossNet for feature interactions, and FP16 inference on device. The two reported rate changes reflect separate project iterations.

GERBIL

An end-to-end recommendation framework bringing together distributed feature engineering, model training, and online inference.

I created GERBIL to turn lessons from production recommendation systems into reusable implementations—with particular attention to consistency between training and serving.
